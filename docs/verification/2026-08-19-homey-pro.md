## Live-derived automatic-flushing ruling

- Enable: exactly one PUT with `{config:{auto_flush_active:true,flush_confirmed:true}}`.
- Disable: exactly one PUT with `{config:{auto_flush_active:false}}`; existing confirmation is not revoked.
- Effective enabled state: `auto_flush_active` is true and, only when `flush_confirmation_required` is explicitly true, `flush_confirmed` is also true.
- PUT is never automatically retried after an ambiguous transport failure.
- Homey confirmation comes from subsequent backend reads. Watersystems UI state may remain stale until logout/login.
