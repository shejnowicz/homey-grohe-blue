GROHE Blue Home for Homey

Monitor your GROHE Blue Home from Homey Pro. View online state, filter and CO₂ levels, remaining capacity, measurement time, idle time, and water-cycle counters. Receive low-level alarms and use Flow cards for state changes and low filter or CO₂ levels.

Automatic flushing can be enabled or disabled from Homey and is reported as successful only after the GROHE API confirms the requested state. Cloud reads are serialized with writes, measurements are retained during temporary failures, and Homey availability changes only after repeated read failures.

A GROHE Watersystems account, GROHE Blue Home appliance, internet connection, and compatible Homey Pro are required.

This developer build has passed local automated tests and Homey manifest validation. Live Homey Pro installation, account pairing, and real-appliance verification remain pending.
